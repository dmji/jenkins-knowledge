# Demo Environment: test data

The demo uses the pinned Jenkins 2.356 / Java 17 image and plugin closure described in [the integration test reference](../../tests/jenkins-2.356/README.md). It includes a pinned Shared Library revision and deterministic jobs/data for collection and consumer checks.

This is a test fixture, not a compatibility promise for another Jenkins installation. Do not import demo tokens, jobs, or plugin versions into production without independent review.
